# cn2en_med_diy

医学学术写作中译英专用技能，特别适用于叙述性综述（narrative review）。

## 功能

将中文医学段落翻译成出版级英文，包含两步工作流：
1. **风格评估**：分析原文文本特征、语域、术语风格
2. **翻译输出**：基于风格分析输出出版级英文译文

## 触发词

医学翻译、中译英、医学论文翻译、clinical translation、narrative review翻译

## 文件结构

```
cn2en_med_diy/
├── SKILL.md          # 技能定义与SOP
├── README.md         # 本说明文件

```

## 适用场景

- 叙述性综述英文翻译
- 临床试验报告翻译
- 医学术语确保CONSORT/PRISMA/MeSH标准
- 发表级英文学术写作
